Parte 0 — A matemática da IA sem medo

Série "Como um ChatGPT funciona por dentro" · Parte 0 de 3

Para entender como um modelo de linguagem funciona, não é preciso dominar cálculo nem álgebra avançada. O funcionamento se apoia em cinco operações, que se resumem a somar e multiplicar, mais uma exponencial e uma divisão na seção 4.

Neste post, as cinco aparecem num caso medido. O pocketchat é um modelo de linguagem pequeno, construído do zero e treinado num notebook, com textos em inglês. A Parte 1 mostra como ele foi feito. Quando recebe o começo de frase

Water is made of hydrogen and

("A água é feita de hidrogênio e"), ele calcula uma porcentagem para cada palavra que pode vir em seguida:

Próxima palavra Porcentagem
oxygen (oxigênio) 52,9%
hydrogen (hidrogênio) 6,6%
carbon (carbono) 4,9%
nitrogen (nitrogênio) 3,5%
table (mesa) 0,0001%

Todos os números das seções 1 a 4 foram medidos nesse modelo. Cada seção mostra uma das operações que levam a essas porcentagens.

Neste post:

  1. Como uma palavra é representada por números
  2. Como se mede a semelhança entre duas palavras
  3. Como o modelo dá uma nota a cada próxima palavra possível
  4. Como as notas viram porcentagens
  5. Como o modelo corrige os próprios números

Pré-requisitos: somar e multiplicar. Os trechos de código são opcionais e usam Python básico.

1. Palavras representadas por números

Um modelo de linguagem só faz contas, então cada palavra precisa ser representada por números. No pocketchat, cada palavra é uma lista de 512 números. Os quatro primeiros números de três dessas listas:

Palavra Posição 1 Posição 2 Posição 3 Posição 4 Restante
oxygen −0,012 −0,022 0,053 0,054 mais 508 números
nitrogen −0,010 0,007 0,007 −0,013 mais 508 números
table −0,066 −0,052 −0,005 −0,063 mais 508 números

Todas as palavras usam as mesmas 512 posições, na mesma ordem. É isso que permite compará-las.

Uma lista de números com posições fixas se chama vetor. Nos modelos de linguagem, o vetor de uma palavra se chama embedding.

Sobre essas listas:

  • ninguém definiu o que cada posição significa. Não existe uma posição "é um gás" nem uma posição "é um móvel";
  • no começo do treino, os 512 números de cada palavra são sorteados;
  • durante o treino, eles são ajustados pela regra da seção 5, com um único objetivo: prever a próxima palavra.

Olhando só para os números de uma lista, não dá para dizer nada sobre a palavra. A informação aparece quando duas listas são comparadas, que é a próxima operação.

2. Semelhança entre duas palavras

Para medir a semelhança entre duas palavras, multiplica-se o número de cada posição de uma lista pelo número da mesma posição da outra, e somam-se os resultados.

Com listas curtas, a conta inteira cabe numa linha:

[2; 0; 1] · [3; 4; 5] = (2 × 3) + (0 × 4) + (1 × 5) = 11

Com as listas do pocketchat, a conta é a mesma, com 512 multiplicações em vez de três. Para oxygen e nitrogen, ela começa assim:

(−0,012 × −0,010) + (−0,022 × 0,007) + (0,053 × 0,007) + (0,054 × −0,013)
+ ... mais 508 multiplicações

O computador faz as 512 multiplicações e soma. O resultado para quatro pares de palavras:

Par Semelhança
oxygen · hydrogen 0,64
oxygen · nitrogen 0,62
oxygen · carbon 0,46
oxygen · table 0,20

Quanto maior o resultado, mais parecidas as listas. Cada multiplicação dá um número positivo quando os dois números têm o mesmo sinal, e negativo quando os sinais são opostos. As listas de oxygen e nitrogen têm o mesmo sinal em 341 das 512 posições. As de oxygen e table, em 292.

Ninguém informou ao modelo que oxigênio, hidrogênio e nitrogênio são elementos químicos. As listas dessas palavras ficaram parecidas durante o treino. A seção 5 mostra como.

def semelhanca(a, b):
    return sum(x * y for x, y in zip(a, b))

semelhanca([2, 0, 1], [3, 4, 5])   # 11

Essa operação se chama produto escalar. Ela é usada em todas as próximas seções e, na Parte 1, é a base do mecanismo de atenção.

3. A nota de cada próxima palavra

Ao chegar ao fim de "Water is made of hydrogen and", o modelo já calculou uma lista de 512 números para a frase inteira, nas mesmas posições das listas das palavras. A Parte 1 mostra como essa lista é calculada. Os quatro primeiros números dela:

lista da frase: [2,324; −1,347; 0,371; 2,043; ... mais 508 números]

A nota de cada palavra candidata é a semelhança entre a lista da frase e a lista da palavra, calculada como na seção 2. Para oxygen:

(2,324 × −0,012) + (−1,347 × −0,022) + (0,371 × 0,053) + (2,043 × 0,054)
+ ... mais 508 multiplicações
= −0,028 + 0,030 + 0,020 + 0,110 + ...
= 9,76

Para table:

(2,324 × −0,066) + (−1,347 × −0,052) + (0,371 × −0,005) + (2,043 × −0,063)
+ ... mais 508 multiplicações
= −0,153 + 0,070 − 0,002 − 0,129 + ...
= −3,29

As notas das cinco palavras da tabela do início:

Palavra Nota
oxygen 9,76
hydrogen 7,68
carbon 7,39
nitrogen 7,04
table −3,29

A lista de oxygen tem o mesmo sinal da lista da frase em 308 das 512 posições, e por isso a maior parte das multiplicações dá um número positivo. A lista de table tem o mesmo sinal em 234 posições e o sinal oposto em 278, e a soma fica negativa. Uma nota negativa indica só que a palavra é uma continuação improvável.

Repare na organização das contas: as listas das palavras ficam uma embaixo da outra, formando uma tabela, e cada linha é comparada com a mesma lista da frase. Uma tabela de números usada assim se chama matriz. A operação, que produz uma nova lista com um resultado por linha, é a multiplicação de matriz por vetor.

No pocketchat, essa tabela tem 8.192 linhas, uma para cada palavra ou pedaço de palavra que o modelo conhece, e 512 colunas. São 4.194.304 números. O resultado da operação são 8.192 notas, uma para cada próxima palavra possível.

Num modelo de linguagem, essa operação aparece em dois tipos de lugar:

  • No último passo, para dar uma nota a cada próxima palavra, como nesta seção.
  • Nos passos intermediários, outras tabelas transformam uma lista de números em outra lista. É com elas que o modelo calcula a lista da frase. Cada uma dessas tabelas é uma camada da rede neural.

Todos os números das tabelas e das listas de palavras são os parâmetros (ou pesos) do modelo. O pocketchat tem 29,9 milhões. "Um modelo de 7 bilhões de parâmetros" é um modelo em que a contagem desses números dá 7 bilhões. Todos começam sorteados e são ajustados no treino.

4. De notas para porcentagens

As notas indicam a ordem de preferência entre as palavras, mas não são porcentagens. A conversão tem dois passos:

  1. Aplicar a exponencial a cada nota: calcular e elevado à nota, sendo e ≈ 2,718. O resultado é sempre positivo, e cada ponto a mais na nota multiplica o resultado por 2,718.
  2. Dividir cada resultado pela soma dos resultados das 8.192 palavras. Assim, o total dá 100%.
Palavra Nota Passo 1: e^nota Passo 2: porcentagem
oxygen 9,76 17.405 52,9%
hydrogen 7,68 2.166 6,6%
carbon 7,39 1.624 4,9%
nitrogen 7,04 1.145 3,5%
table −3,29 0,04 0,0001%
as outras 8.187 10.569 32,1%
Soma 32.909 100%

Exemplo da conta do passo 2, para oxygen: 17.405 ÷ 32.909 = 0,529, ou 52,9%. As notas aparecem na tabela com duas casas decimais; o passo 1 foi calculado com todas as casas.

import math

def softmax(notas):
    exps = [math.exp(n) for n in notas]
    total = sum(exps)
    return [e / total for e in exps]

softmax([2.0, 1.0, 0.0])   # [0.665, 0.245, 0.090]

Por causa do passo 1, diferenças nas notas viram diferenças grandes nas porcentagens: a nota de oxygen é 2,08 pontos maior que a de hydrogen, e a porcentagem é 8 vezes maior. Mesmo assim, nenhuma palavra fica com 0%. Table tem 0,0001%.

Essa conversão se chama softmax. Depois dela, o modelo sorteia a próxima palavra de acordo com as porcentagens. Em 100 sorteios, oxygen sai cerca de 53 vezes, hydrogen 7 e carbon 5. Quando sai carbon, o modelo escreve "Water is made of hydrogen and carbon", uma frase errada. A Parte 1 volta a esse ponto.

5. Como o modelo corrige os próprios números

As listas das seções anteriores são o resultado do treino. No começo, todas tinham números sorteados. Esta seção mostra a regra que corrige esses números a cada frase de treino.

Não dá para acompanhar à mão a correção de listas de 512 números. Só nesta seção, as contas usam uma versão reduzida: listas de dois números e três palavras. A regra é a mesma que treinou o pocketchat, e os valores iniciais foram sorteados, como num modelo real:

Lista inicial
frase "hydrogen and" [0,5; 0,5]
oxygen [0,2; −0,1]
carbon [−0,3; 0,2]
table [0,1; 0,3]

Antes do treino

Notas (semelhança com a frase) e porcentagens (softmax):

Palavra Nota Porcentagem
oxygen (0,5 × 0,2) + (0,5 × −0,1) = 0,05 32,6%
carbon (0,5 × −0,3) + (0,5 × 0,2) = −0,05 29,5%
table (0,5 × 0,1) + (0,5 × 0,3) = 0,20 37,9%

Com números sorteados, a palavra mais provável depois de "hydrogen and" é table.

A regra de correção

Nos textos de treino do pocketchat, "hydrogen and" aparece 1.021 vezes. A palavra seguinte é oxygen em 323 delas, carbon em 68 e table em nenhuma. Cada ocorrência que entra no treino gera uma correção.

Suponha que a primeira frase de treino termine em "hydrogen and oxygen". A resposta certa é oxygen. A correção é feita assim:

  • Palavra certa: soma-se à lista dela a lista da frase multiplicada por (1 − a porcentagem que ela recebeu). Oxygen recebeu 32,6%, então o multiplicador é 1 − 0,326 = 0,674.
  • Cada palavra errada: subtrai-se da lista dela a lista da frase multiplicada pela porcentagem que ela recebeu. Carbon recebeu 29,5% (multiplicador 0,295); table recebeu 37,9% (multiplicador 0,379).

Essa regra não foi escolhida à mão. Ela é o resultado do cálculo do gradiente da perda (o número que mede o erro do modelo), e bibliotecas como o PyTorch a calculam automaticamente.

Correção 1: a resposta certa é oxygen

Palavra Conta Nova lista
oxygen [0,2; −0,1] + 0,674 × [0,5; 0,5] = [0,2 + 0,337; −0,1 + 0,337] [0,537; 0,237]
carbon [−0,3; 0,2] − 0,295 × [0,5; 0,5] = [−0,3 − 0,148; 0,2 − 0,148] [−0,448; 0,052]
table [0,1; 0,3] − 0,379 × [0,5; 0,5] = [0,1 − 0,189; 0,3 − 0,189] [−0,089; 0,111]

Novas notas e porcentagens:

Palavra Nota Porcentagem
oxygen 0,387 44,6%
carbon −0,198 24,8%
table 0,011 30,6%

A nota de oxygen subiu de 0,05 para 0,387, e oxygen passou a ser a palavra mais provável.

Por que somar a lista da frase faz a nota subir

A nota é a soma de "número da frase × número da palavra", posição por posição. Ao somar à palavra uma fração da lista da frase:

  • nas posições em que a frase tem um número positivo, o número da palavra aumenta, e o produto daquela posição aumenta;
  • nas posições em que a frase tem um número negativo, o número da palavra diminui, e o produto (negativo × negativo) também aumenta.

A nota sobe em todas as posições. No exemplo, a nota de oxygen subiu 0,674 × (0,5 × 0,5 + 0,5 × 0,5) = 0,674 × 0,5 = 0,337: de 0,05 para 0,387. Pelo mesmo raciocínio, subtrair a lista da frase faz a nota das palavras erradas cair.

O tamanho da correção depende do erro. Se oxygen tivesse recebido 95%, o multiplicador seria 1 − 0,95 = 0,05, e a lista de oxygen quase não mudaria. Quanto mais o modelo erra, maior a correção.

Correção 2: a resposta certa é carbon

Agora a frase de treino termina em "hydrogen and carbon". Os multiplicadores saem das porcentagens da tabela anterior:

Palavra Conta Nova lista
carbon [−0,448; 0,052] + (1 − 0,248) × [0,5; 0,5] [−0,072; 0,428]
oxygen [0,537; 0,237] − 0,446 × [0,5; 0,5] [0,314; 0,014]
table [−0,089; 0,111] − 0,306 × [0,5; 0,5] [−0,242; −0,042]
Palavra Nota Porcentagem
oxygen 0,164 36,4%
carbon 0,178 36,9%
table −0,142 26,8%

O resultado

Em duas correções:

  • table teve a lista diminuída nas duas vezes e passou de 37,9% para 26,8%. Nada no processo informa que mesa não é um elemento químico: ela perdeu chance porque não era a resposta em nenhuma das duas frases;
  • oxygen e carbon receberam, cada uma, uma soma da mesma lista da frase, e terminaram quase empatadas, com cerca de 36% cada.

No treino do pocketchat, esse processo se repetiu centenas de milhões de vezes, com quatro diferenças em relação à versão reduzida:

  1. Os multiplicadores são multiplicados também por um número pequeno, chamado taxa de aprendizado (por exemplo, 0,001). Cada correção é bem menor do que no exemplo.
  2. A lista da frase também é corrigida, pela mesma regra: soma-se a ela uma fração da lista da palavra certa e subtrai-se uma fração das listas das palavras erradas. Na próxima frase parecida, ela produz notas melhores.
  3. Todos os parâmetros do modelo são corrigidos, não só as listas das palavras. O PyTorch calcula a correção de cada um.
  4. As respostas certas não aparecem em quantidades iguais. Depois de "hydrogen and", oxygen foi a resposta 323 vezes, e carbon, 68. Oxygen recebeu mais somas, e no modelo treinado tem a nota maior.

O procedimento completo, em que cada parâmetro é corrigido na direção que reduz o erro, se chama descida de gradiente.

É assim que as listas da seção 1 chegaram aos valores que têm. Oxygen, hydrogen e nitrogen aparecem depois dos mesmos tipos de começo de frase. A cada um deles, as listas das três recebem somas de listas de frase parecidas, e por isso ficam parecidas entre si: a semelhança entre oxygen e nitrogen é 0,62. Table aparece depois de outros começos de frase e recebe somas de outras listas: a semelhança entre oxygen e table é 0,20.

Resumo

Para completar "Water is made of hydrogen and", o pocketchat:

  1. representa cada palavra com uma lista de 512 números (vetor, ou embedding);
  2. mede semelhanças multiplicando posição por posição e somando (produto escalar);
  3. compara a lista da frase com a lista de cada uma das 8.192 palavras, numa tabela (matriz), e obtém uma nota por palavra: 9,76 para oxygen, −3,29 para table;
  4. converte as notas em porcentagens (softmax) e sorteia a próxima palavra: 52,9% para oxygen;
  5. no treino, somou à lista da palavra certa e subtraiu das erradas frações da lista da frase, proporcionais ao erro (descida de gradiente).

Para fixar

  1. Calcule a semelhança entre as listas [1; 2; 3] e [4; 0; 2].
  2. Na tabela da seção 4, o resultado do passo 1 para nitrogen é 1.145, e a soma é 32.909. Faça a conta do passo 2.
  3. Se as 8.192 palavras recebessem a mesma nota, qual seria a porcentagem de cada uma?
  4. Na seção 5, se o modelo tivesse dado 90% de chance a oxygen antes da correção 1, por qual número a lista da frase seria multiplicada antes de ser somada à lista de oxygen?
  5. Por que oxygen e carbon terminaram a seção 5 com porcentagens parecidas?

Respostas:

  1. (1 × 4) + (2 × 0) + (3 × 2) = 10.
  2. 1.145 ÷ 32.909 = 0,035, ou 3,5%.
  3. 100% ÷ 8.192 = 0,012% cada. Notas iguais geram o mesmo resultado no passo 1, e a divisão pela soma dá partes iguais.
  4. 1 − 0,90 = 0,10. A correção seria pequena, porque o modelo já estava quase acertando.
  5. Porque, nas duas correções, as listas de oxygen e de carbon receberam somas da mesma lista da frase, uma vez cada. Cada uma teve uma soma (quando era a resposta certa) e uma subtração (quando não era), e as duas terminaram com notas próximas.
